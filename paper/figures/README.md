# Generated manuscript figures

Run `notebooks/04_final_analysis.ipynb` after the two main experiments to regenerate the six figures referenced by the manuscript. Copy the generated PNG files from the Drive `paper_outputs/figures/` directory into this folder for a local LaTeX build.

Expected filenames:

- `visuelle_local_effects.png`
- `freshretail_local_effects.png`
- `freshretail_target_day_profile.png`
- `local_rank_stability.png`
- `visuelle_metric_normalization.png`
- `freshretail_metric_normalization.png`

The arXiv source archive distributed with the preprint contains the static PNG files used in the compiled submission.
